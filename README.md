# مشروع محاكاة USDT Flash التعليمي

هذا المشروع تعليمي يوضح كيفية خداع المستخدمين بإظهار توكنات USDT مزيفة في محافظهم. الهدف هو التوعية وتعليم المستخدمين كيفية التمييز بين التوكنات الحقيقية والمزيفة.

## ⚠️ تحذير هام

**هذا المشروع مخصص للأغراض التعليمية فقط ولا يجب استخدامه في أي نشاط احتيالي.**

الهدف من هذا المشروع هو توعية المستخدمين بكيفية التعرف على التوكنات المزيفة وحماية أنفسهم من عمليات الاحتيال.

## 🎯 الهدف

تصميم مشروع تعليمي يعرض كيفية خداع المستخدم بأن رصيد USDT وصل إلى محفظته، عن طريق إرسال توكن مزيف بنفس اسم ورمز USDT، يتم نشره فعليًا على شبكة Ethereum، ليظهر للضحية داخل محفظته كأنه استلم USDT حقيقي.

## 📋 المكونات الرئيسية

1. عقد ذكي ERC20 مزيف يحمل نفس خصائص USDT:
   - الاسم: Tether USD
   - الرمز: USDT
   - الكسور العشرية: 6
   - يحتوي على دالة mint() لإنشاء التوكنات
   - يحتوي على دالة transfer() لإرسال التوكنات

2. سكريبت نشر العقد على شبكة Ethereum

3. سكريبت توزيع التوكنات المزيفة على محافظ حقيقية

## 🚀 كيفية الاستخدام

### 1. إعداد المشروع

```shell
# تثبيت المكتبات اللازمة
npm install

# إنشاء ملف .env
cp .env.example .env
```

قم بتعديل ملف `.env` وإضافة المعلومات المطلوبة:
- مفتاح API للاتصال بشبكة Ethereum (Infura أو Alchemy)
- المفتاح الخاص للحساب الذي سيقوم بنشر العقد وتوزيع التوكنات
- قائمة بعناوين المحافظ التي سيتم إرسال التوكنات المزيفة إليها

### 2. نشر العقد

```shell
# نشر العقد على شبكة الاختبار Sepolia
npx hardhat run scripts/deploy.js --network sepolia

# نشر العقد على الشبكة الرئيسية (تحذير: يتطلب ETH حقيقي)
npx hardhat run scripts/deploy.js --network mainnet
```

### 3. توزيع التوكنات

```shell
# توزيع التوكنات على العناوين المحددة في ملف .env
npx hardhat run scripts/distribute.js --network sepolia
# أو
npx hardhat run scripts/distribute.js --network mainnet
```

## 🛡️ كيفية الحماية من هذا النوع من الاحتيال

1. التحقق دائمًا من عنوان العقد الذكي للتوكن
2. عنوان USDT الرسمي على شبكة Ethereum هو: `0xdAC17F958D2ee523a2206206994597C13D831ec7`
3. عدم الثقة في التوكنات التي تظهر فجأة في المحفظة
4. استخدام أدوات مثل Etherscan للتحقق من مصدر التوكنات
